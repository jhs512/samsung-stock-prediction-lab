# 코사인 유사도 기반 패턴 예측법 — 최신 안내

2026-10-08 작성, 가격 스냅샷은 2026-10-07까지다. 모든 그래프는 삼성전자 및 SK하이닉스 전체 보고서의 고정 입력 가격과 검색 결과에서 가져온다.

최근 차트, 닮은 과거, 이후 결과를 세 단계로 설명한다. 설명용 네 사례는 결과를 확인한 뒤 선택했으며 예측 성공률 산정에 따로 사용하지 않았다. 무작위 버튼은 고정 조건에서 실제로 검색된 과거 시험 사례를 다시 보여준다.

투자금 계산은 기준일 다음 거래일 시가 매수, 기준일에서 20거래일 뒤 종가 매도를 가정한다. 정수 주, 잔액 현금, 입력한 매수 및 매도 비용을 포함하며, 현금 이자·배당·중간 매도는 제외한다. 시가·종가에 정확히 체결된다는 가정이며 실전 전략의 수익이 아니다. 기본 비용 0%는 실제 증권사 요율을 뜻하지 않는다.

재생성하려면 전체 저장소를 내려받고 Python 3.14와 NumPy 2.5.3을 설치한 뒤:

```
python docs/pattern-guide/build_guide.py
```

옆 디렉터리의 두 report_data.json 및 daily_prices.csv가 필요하다. 사이트는 외부 자료를 새로 다운로드하지 않는다. 각 종목의 원자료, 검증 기록과 48조건 실행 코드는 전체 보고서에 포함되어 있다.
