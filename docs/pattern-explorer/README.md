# 2026 유사 패턴 탐색기

삼성전자와 SK하이닉스의 2026년 각 기준일에 대해 100거래일 입력을 기본으로 과거 유사 구간을 전부 검색한다. 탐색 길이 10·20·60·100일, 코사인 유사도 0.98 초과. 각 입력 종가 구간은 최저를 빼고 L2 정규화한다(최저·최고 정규화 후 코사인과 동일). 상수 구간은 제외한다.

검색 후보는 2019년 이후이며 20거래일 뒤 결과가 2025년 안에 관측된 구간으로 제한한다. 현재 입력과 과거 입력·결과가 겹치는 구간도 제외한다. 미래 2026년 자료를 과거 검색에 사용하지 않는다. 상위 개수 제한이나 최소 3개 규칙은 없다. 화면에는 겹치는 모든 구간을 보여주고, 유사도 내림차순 탐욕 선택으로 입력+결과가 겹치지 않는 사례 수도 별도로 표시한다. 이는 최대 가능한 비중복 개수를 뜻하지 않는다.

랜덤 날짜는 20일 결과가 완성된 모든 2026년 거래일에서 균등 추출하며, 랜덤 과거는 선택 날짜에 검색된 모든 후보에서 균등 추출한다. 수익·적중 여부로 선택하지 않는다. 계산표는 다음 거래일 시가 매수 / 기준일+20거래일 종가 매도, 정수 주·원 단위 비용 반올림·잔액 현금을 포함한다. 실제 실행 전략의 수익을 검증한 것은 아니다.

`all-2026-100d-matches.csv`는 양 종목의 모든 2026년 날짜에 대한 100일 검색 결과다. 중복·겹침을 포함한다. 최신 날짜는 아직 실제 결과가 없어 빈 값이다. 원자료는 인접 보고서의 고정 OHLC CSV이며 2026-10-07까지다.

재생성: Python과 NumPy를 설치하고 `python docs/pattern-explorer/build_explorer.py` 실행. `template.html`이 페이지 원본이다.
