AI가 제안한 공개 계획

  1. 실제 일별 자료와 결측부터 확인한다.
  2. 가격·수익률·이동평균·어제 가격을 만든다.
  3. 시간순으로 나눠 7개 학습 후보를 비교한다.
  4. 검증에서 선택한 뒤, 미사용 기간을 한 번 평가한다.
검증할 가설 · H1 최근 흐름을 더하면 기준보다 평균 오차가 줄어든다. H2 비슷한 가격 변수의 영향을 줄이는 Ridge·Lasso가 일반 선형회귀보다 안정적이다.

이 페이지의 계획·선택 이유·실험 기록은 공개 가능한 작업 요약입니다. 교육용 예측 실험이며 투자 판단을 위한 서비스가 아닙니다.

05 / 기준과 학습 모델 비교 · 1분

복잡해졌다고 더 잘 맞힐까요?

MAE는 예측과 실제의 차이를 절댓값으로 바꾼 뒤 평균한 값입니다. 원 단위이며 작을수록 좋습니다.

모델 선택에 사용한 2024년 검증
후보MAE (원)

Python으로 실제 수행한 실험

LinearRegression · 네 입력을 조합한 직선을 학습합니다.

Ridge · 계수의 크기를 줄입니다. α = 0.1, 10, 100

Lasso · 일부 계수를 0으로 만들 수도 있습니다. α = 1, 10, 100

α는 계수에 거는 제약의 강도입니다. 같은 4개 피처, 같은 학습 구간으로 7개 후보만 비교했습니다. 난수 분할·시드 탐색은 하지 않았습니다.

검증에서 이미 기준이 앞섰습니다.
Lasso α=1은 학습 후보 중 최저 MAE이지만 기준보다 2.98원 큽니다. 운영 후보는 기준 모델을 유지하고, Lasso를 학습 모델 체험용으로 보존합니다.

검증 점수로 선택을 확정했습니다. 다음 단계의 시험 점수로 모델을 교체하거나 다시 튜닝하지 않습니다.
