# 삼성전자 유사 패턴 실험 보고

결론: 이번 조건에서는 채택할 만한 예측력을 확인하지 못했다.

- 목표: 다음 20거래일 누적 가격 수익률. 삼성전자 단일 종목.
- 48조건: 입력 10/20/60/100일 × 유사도 .90/.95/.98 또는 상위 3/5/10개 × 평균/중앙값.
- 2022~2025년 검증에서 과거 평균 MAE 6.485%p보다 작은 조건은 0개.
- 선택 조건(100일/.98 초과/평균)은 검증 897일 모두 과거 평균으로 대체. 중앙값 조건과 동률이며 이름순 규칙으로 선택. 100일이 우수하다는 근거가 아니다.
- 2026년 166일: MAE 16.604%p vs 평균 16.990%p. 실제 패턴 사용 10일, 대체 156일.
- 방향 적중 71.69%는 항상 상승 예측과 동일. 하락 적중 0%, 균형 적중 50%.
- 20일 블록 부트스트랩 개선 95% 구간 [0.000, 1.157]%p. 탐색적 점검이며 선택 불확실성 전체를 포함하지 않는다.
- 겹치지 않는 첫날 기준 9건에서는 둘 다 MAE 23.562%p, 패턴 사용 0일.
- 같은 조건을 Yahoo 원종가로 고정 점검: MAE 16.638%p vs 평균 16.979%p, 패턴 사용 9/166일.
- 2026-10-07 최신: 독립 후보 0개. +1.433% 출력은 과거 평균이며 실제 패턴 예측이 아니다. 미래 결과 미관측.

검증 설계: 각 연도 시작 전에 결과까지 관측된 사례만 연초 고정. 2026년 사례 결과는 전혀 학습/검색 목록에 사용하지 않음. 모든 조건은 동일한 공통 과거 평균 기준과 비교. 2026년은 이전 실험에서 이미 본 자료이므로 새 맹검 시험은 아님.

원본 변경: 미래 검색 차단, 중복 사건 제외, 3개 미만은 평균 대체, 5일 일별 등락률 평균 대신 20일 누적 수익률. 원본 그대로의 검증이 아님.

자료 한계: Naver 1905행 실제 API 스냅샷, 2019-01-02~2026-10-07. Yahoo 겹치는 1902행 중 종가 차이 40일(2026년 14일), 과거 날짜 3개 없음. 두 자료를 혼합 보정하지 않음. 배당 제외, Naver 가격 조정 미확인. 거래비용 후 수익이나 실전 투자 성과를 검증하지 않음.
